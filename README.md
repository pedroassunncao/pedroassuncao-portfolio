# Pedro Assunção — Sites e portfólio

Site comercial de Pedro Assunção, com apresentação de serviços, portfólio e pedido de orçamento pelo WhatsApp **(71) 98199-1535**.

O código está na pasta [`portfolio-pedro-assuncao-v4`](./portfolio-pedro-assuncao-v4). Consulte o [README do site](./portfolio-pedro-assuncao-v4/README.md) para executar, configurar o endereço público e editar serviços e projetos.

```bash
cd portfolio-pedro-assuncao-v4
npm install
npm run dev
```

O portfólio apresenta demonstrações conceituais, identificadas como tal. O orçamento prepara uma mensagem; o visitante confirma o envio no WhatsApp.
